# Life Journal v5.1.12

本版围绕私人生活记录体验和数据生命周期完善：六类生活卡片、正文插入与阅读方式、永久删除与引用治理，以及可选 AI 服务商/模型管理。正式发行状态和附件完整性以实际 Release 及验证收据为准。

## Added

- 交通类型选择与各类型选填信息；独立时区开关保留历史 IANA 时区和绝对时刻。
- 完整阅读、纯正文及卡片汇总，按当前正文顺序和稳定UUID定位。
- 当前、历史、回收站及失效索引引用分类，可预览一致性检查、重建和失效索引维护。
- AI服务商共享多个模型，12种可编辑预设，OpenAI Compatible/Ollama/Anthropic/Gemini协议，模型列表和现有任务各自默认模型。

## Changed

- 六类卡片各自保留生活记录的视觉特色，减少空行与无内容区域，完整显示自由文字，适配窄屏与个性化配色。
- “插入卡片”与 @l/@f/@m/@s/@g/@t 菜单使用明确确认，旧文本标记通过兼容入口继续使用，保留光标、输入法、撤销及草稿保护。
- AI默认模型停用、删除或缺失时明确提示，不自动选用另一服务商；所有协议非流式，真实能力和参数以实际模型说明为准。

## Fixed

- 永久删除的相关调用/候选引用与派生索引清理统一按事务处理，继续保护共享资源和历史版本。
- 资源删除前分类展示引用影响，避免将失效派生索引误认为当前正文内容。

## Security

- AI模型列表和生成共用HTTPS、SSRF/DNS校验与固定IP连接、拒绝重定向、超时、请求/响应大小限制及脱敏错误。
- 服务密钥仅使用已有环境变量引用；正文及照片仍需明确授权，不进行自动重试或自动付费服务商切换。
- 保留全部现有安全、许可、对应源码和发行门禁；不改动410份历史法律文本。

## Migration / Compatibility

- v5.1.11 → v5.1.12沿用现有 `0021_anniversary_calendar`，无新增Alembic迁移、强制Compose变化或AI重新配置。
- 兼容原文章、历史修订、卡片UUID及未知字段、交通时区、旧 @ 标记、现有 AI 配置与密钥引用、自定义主题。
- 升级前创建并验证完整备份；新字段/AI配置写入后，回滚应使用精确旧构建和升级前备份，在独立目标先验证恢复。详细步骤见附件 UPGRADE.md 和 `docs/v5.1.12-release.md`。

真实AI服务商、真实通知和实际NAS/Windows Docker Desktop待本地验收；只宣称合成协议与自动化实际完成的验证。UPGRADE-001历史现场根因仍未确认。
