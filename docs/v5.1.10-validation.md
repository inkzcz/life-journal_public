## 行为与兼容性

- `/write` 默认日常记录，选择旅行后自动设置现有 `article.travel_enabled`。
  新建时由管理员端点 `POST /api/admin/content/types/default-article` 幂等解析基础类型。
  不假定数据库 UUID，不要求先配置类型/模板；碰到已自定义、停用或绑定模板的同名类型会保留并另选安全基础类型。
- 普通导航和新建页隐藏模板入口；保留模板表、所有记录绑定、模板 API、历史模板编辑与可选高级内容类型。
- 模式切换仅改变旅行开关。正文、卡片 UUID、动态字段、媒体 UUID、日期及已保存行程保持；关闭旅行只隐藏相应控件。
- 编辑器、正文和专题页共用 EntryCard。浅/深色使用已有主题变量，无新图标库、图片、字体或强制依赖。
  SVG 为本轮原创基本几何图形；字段/照片为空时隐藏，长文本换行。序列化仍为 `:::lj-entry-v1`。
- 管理员通知设置明文显示 URL，不向匿名用户提供配置。变量只允许路径/查询参数值，分别 UTF-8 编码；
  变量点号也编码，避免 `.`/`..` 路径归一化。域名、协议、端口、用户信息、查询键和片段不接受变量。
  HTTPS、DNS/IP、精确内网 origin/IP 白名单、禁止重定向、超时、响应大小、有限重试和不确定状态保持。
  错误只返回固定消息/代码，不回显 URL 或凭据。扫描仅覆盖已知秘密模式，不保证识别一切未知秘密。
- 无新增表或 Alembic 迁移，Head 仍是 `0021_anniversary_calendar`。Compose、NAS 数据映射、备份格式及迁移保护未改。

## 可复现的合成界面预览

```sh
cd frontend
npm ci
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

打开 `http://127.0.0.1:5174/preview-writing.html`，查看六类卡片、日常/旅行新建与通知配置，切换浅/深色并缩窄视口。
这是独立开发入口，未被生产 index/路由导入；所有 API 在浏览器内存中合成，未知/外部请求直接拒绝，刷新重置。
不会读取数据库或媒体，不会发送通知，所用 SVG 封面为原创合成素材。
此预览不代替真实 API、Docker 或平台验收。真实页面仍通过原有登录/CSRF/管理员权限保护。

复用现有只读 CI，按 VERSION 构建一次 Linux/amd64 测试候选；单业务镜像、单 TAR、重复导入、所有镜像层、

`--validate-only` 不生成可发行资产、不上传 TAR/数据库/媒体/原始日志；v5.1.9 的发行授权不扩展到 v5.1.10。
